### 3. AudioManager 使用 AssetsLoadManager
**文件**: `Assets/Scripts/Fuel/Manager/AudioManager/AudioManager.cs:203-212`
**改动**:
- `GetAudioClip` 方法改用 `AssetsLoadManager.Instance.LoadSync<AudioClip>`
- AudioManager 是 `Singleton<AudioManager>`（纯C#），通过 `AssetsLoadManager.Instance` 访问
- AssetsLoadManager 是 `MonoSingleton`，在 Unity 场景中自动初始化
- 保留 Resources.Load 作为 fallback（如果 AssetsLoadManager 未初始化）
```csharp
private AudioClip GetAudioClip(string clipName)
{
    string audioPath = AudioPath + clipName;
    AudioClip audioClipNew = null;
    if (AssetsLoadManager.Instance != null)
    {
        audioClipNew = AssetsLoadManager.Instance.LoadSync<AudioClip>(audioPath);
    }
    if (audioClipNew == null)
    {
        audioClipNew = Resources.Load<AudioClip>(audioPath);
    }
    if (audioClipNew != null)
        _allClips.TryAdd(clipName, audioClipNew);
    return audioClipNew;
}
```
**注意**: 需要在 AudioManager.cs 顶部添加 `using Fuel.AssetManager;` 引用。

### 10. AssetsLoadManager 类型分发重构（全面）
**文件**: `Assets/Scripts/Fuel/Manager/AssetManager/AssetsLoadManager.cs`
**改动**: 提取类型到池实例的映射字典，消除所有重复的 if-else 类型分发代码

**步骤**:
1. 添加池接口 `IAssetPool` 统一各池的 `GetSync`/`GetAsync`/`Recycle` 方法签名
2. 在 `OnInit` 中建立 `Type → IAssetPool` 映射字典
3. 重构 `LoadSync<T>`、`LoadAsync<T>`、`LoadSync(path, type)`、`LoadAsync(path, type)`、`LoadAsync<T>(path, code, action)`、`LoadAsync<T>(path, code)` 共 6 个方法
4. 重构 `Recycle<T>` 和 `RecycleByGroup<T>` 方法

```csharp
// 新增接口
internal interface IAssetPool
{
    UnityEngine.Object GetSync(string path, string groupName);
    UniTask<UnityEngine.Object> GetAsync(string path, string groupName);
    void Recycle(UnityEngine.Object obj, string groupName);
    void RecycleByGroup(string groupName);
    void DestroyByGroup(string groupName);
}

// 在 OnInit 中注册
private readonly Dictionary<Type, IAssetPool> _poolMap = new Dictionary<Type, IAssetPool>();

protected override void OnInit()
{
    base.OnInit();
    _poolMap[typeof(GameObject)] = new GameObjectPoolAdapter();
    _poolMap[typeof(Material)] = new MaterialPoolAdapter();
    // ... 其他类型
}

// LoadSync 简化为
public T LoadSync<T>(string path, string groupName = "") where T : UnityEngine.Object
{
    if (_poolMap.TryGetValue(typeof(T), out var pool))
        return pool.GetSync(path, groupName) as T;
    return InternalLoadSync<T>(path, groupName);
}
```

**注意**: 需要为每个池类型创建适配器类（实现 IAssetPool），或直接在各池类上实现接口。此改动范围最大，需要仔细测试每种资源类型的加载/回收。
